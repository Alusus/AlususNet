# الأسس نت

<div dir=rtl>

[[English]](README.md)

مكتبة عميل لمنصة الأسس نت - خدمة استضافة ونشر لتطبيقات الأسس.

## نظرة عامة

توفر مكتبة الأسس نت مكتبة عميل وأداة واجهة أوامر شاملتين لنشر مشاريع الأسس على منصة استضافة الأسس نت. تتولى المكتبة عمليات نشر المشاريع والنسخ الاحتياطي لقواعد البيانات واسترجاعها، مع توثيق آمن وإعداد تفاعلي.

## التنصيب

اشمل المكتبة في مشروعك على الأسس:

<div dir=ltr>

```
import "Apm";
Apm.importPackage("Alusus/AlususNet@0.2");
```

</div>

## واجهة برمجة المكتبة

### الصنف Client

يوفر الصنف `Client` وصولاً برمجيًا لخدمات الأسس نت.

#### الإنشاء

يمكن إنشاء كائن من الصنف Client بعدة طرق:

<div dir=ltr>

```
// إنشاء أساسي باستخدام اسم المشروع فقط
def client: SrdRef[AlususNet.Client] = AlususNet.Client("my-project");

// إنشاء مع رمز API (مفيد لأنظمة CI/CD)
def client: SrdRef[AlususNet.Client] = AlususNet.Client("my-project", "api-token-here");

// إنشاء مع التحكم بوضع الإسهاب (verbose)
def client: SrdRef[AlususNet.Client] = AlususNet.Client("my-project", "api-token", true);
```

</div>

**المعطيات:**
- `projectName` (String): اسم مشروعك على الأسس نت. يجب أن يحتوي فقط على أحرف إنجليزية صغيرة وأرقام وشرطات (-)، ولا يجب أن يبدأ أو ينتهي بشرطة.
- `apiKey` (String، اختياري): رمز API الخاص بك على الأسس نت. إذا لم يُوفَّر، ستتم مطالبتك ببيانات تسجيل الدخول.
- `verbose` (bool، اختياري): تفعيل تسجيل مفصّل لطلبات HTTP. القيمة الافتراضية: `false`.

#### الدالة setDesiredPlan

تحدد باقة الاستضافة التي يجب أن تستخدمها `publish`، متجاوزةً بذلك أسئلة اختيار الباقة التفاعلية.

<div dir=ltr>

```
client.setDesiredPlan("pro-plan");
client.publish(8080);
```

</div>

**المعطيات:**
- `planName` (String): اسم باقة الاستضافة المراد استخدامها لهذا المشروع.

**السلوك:**
- عند تحديدها، تستخدم `publish` هذه الباقة تلقائيًا دون سؤال المستخدم عن الباقة المطلوبة.
- إذا كان المشروع موجودًا مسبقًا بباقة مختلفة، تتولى `publish` تلقائيًا تغيير الباقة إلى الباقة المطلوبة (عبر نفس آلية `changePlan`) قبل تحميل الإصدار الجديد.
- تفشل العملية برسالة خطأ إن لم توجد باقة مطابقة للاسم المُعطى.

#### الدالة publish

تنشر مشروعك على الأسس نت، مما يجعله متاحًا على المنصة.

<div dir=ltr>

```
// نشر بسيط مع تحديد منفذ الخادم
client.publish(8080);

// نشر مع تحديد مسار المشروع والملف التنفيذي الرئيسي
client.publish(8080, "/path/to/project", "my-app");
```

</div>

**المعطيات:**
- `serverPort` (Int): منفذ HTTP الذي سيستمع عليه تطبيقك.
- `projectPath` (String، اختياري): مسار مجلد مشروعك. إذا لم يُحدَّد، يُستخدم المجلد الحالي.
- `starter` (String، اختياري): اسم الملف التنفيذي الذي يشغّل تطبيقك.

**السلوك:**
- يتحقق من صحة صيغة اسم المشروع
- يجلب باقات الاستضافة المتوفرة
- يوثّق الاتصال مع الأسس نت (عند الحاجة)
- يُعِدّ المشروع وخطة الدفع (تفاعليًا، إلا إذا حُدِّدت باقة مسبقًا عبر `setDesiredPlan`)
- ينشئ ملفًا مضغوطًا (tarball) لمشروعك ويرفعه
- يعرض تقدم عملية الرفع

#### الدالة changePlan

تغيّر باقة الاستضافة لمشروع موجود.

<div dir=ltr>

```
// تغيير الباقة بالاسم
client.changePlan("pro-plan");

// تغيير الباقة بالاسم مع رمز ترويجي
client.changePlan("pro-plan", "SAVE20");
```

</div>

**المعطيات:**
- `planName` (String): اسم باقة الاستضافة المراد التبديل إليها. يُستخرج معرّفها (ID) تلقائيًا من هذا الاسم.
- `promotionCode` (String، اختياري): رمز ترويجي لتطبيقه على اشتراك الباقة الجديدة.

**السلوك:**
- يوثّق الاتصال مع الأسس نت
- يجلب باقات الاستضافة المتوفرة ويستخرج معرّف الباقة من `planName`
- يطلب تغيير الباقة، ويطالب بإعداد ملف الدفع أو إدخال رمز ترويجي جديد عند الحاجة

#### الدالة restoreDbBackup

يرفع ويسترجع نسخة احتياطية لقاعدة بيانات PostgreSQL إلى حاوية مشروعك.

<div dir=ltr>

```
client.restoreDbBackup("/path/to/backup.sql");
```

</div>

**المعطيات:**
- `restore_db_path` (String): مسار ملف النسخة الاحتياطية لـ PostgreSQL المراد رفعه.

**السلوك:**
- يوثّق الاتصال مع الأسس نت
- يرفع ملف النسخة الاحتياطية على دفعات
- يعرض تقدم عملية الرفع
- يسترجع قاعدة البيانات على الخادم

#### الدالة listPlans

تجلب وتطبع قائمة باقات الاستضافة المتوفرة على الأسس نت.

<div dir=ltr>

```
client.listPlans();
```

</div>

**السلوك:**
- يجلب باقات الاستضافة المتوفرة (دون الحاجة لتوثيق)
- يطبع اسم كل باقة ووصفها وكلفتها الشهرية

#### الدالة downloadDbBackup

تنشئ نسخة احتياطية لقاعدة بيانات PostgreSQL الخاصة بمشروعك وتُحمّلها.

<div dir=ltr>

```
client.downloadDbBackup("/path/to/save/backup.sql");
```

</div>

**المعطيات:**
- `backup_db_path` (String): المسار الذي سيُحفظ فيه ملف النسخة الاحتياطية.

**السلوك:**
- يوثّق الاتصال مع الأسس نت
- يطلب إنشاء نسخة احتياطية لقاعدة البيانات
- ينتظر حتى تصبح النسخة الاحتياطية جاهزة
- يُحمّل ملف النسخة الاحتياطية
- يحفظه في المسار المحدد

## أداة واجهة الأوامر

تتضمن مكتبة الأسس نت واجهة أوامر للتعامل مع المنصة.

### بناء أداة واجهة الأوامر

لبناء أداة واجهة الأوامر:

<div dir=ltr>

```bash
alusus cli.alusus build-cli
```

</div>

ينشئ هذا الأمر ملفًا تنفيذيًا في `./Build/alusus-net`.

### أوامر واجهة الأوامر

#### plans

يجلب ويعرض قائمة باقات الاستضافة المتوفرة على الأسس نت.

<div dir=ltr>

```bash
alusus-net plans
```

</div>

#### publish

ينشر مشروعك على منصة الأسس نت.

<div dir=ltr>

```bash
alusus-net publish <projectName> <projectPath> <port> [starter] [apiToken]
```

</div>

**المعطيات:**
- `projectName`: اسم المشروع على الأسس نت
- `projectPath`: مسار مجلد المشروع
- `port`: منفذ HTTP الذي سيستمع عليه التطبيق
- `starter` (اختياري): اسم الملف التنفيذي للمشروع
- `apiToken` (اختياري): رمز API للأسس نت. إذا لم يُوفَّر، ستتم مطالبتك بتسجيل الدخول

**مثال:**

<div dir=ltr>

```bash
alusus-net publish my-app ./my-project 8080 server
```

</div>

#### change-plan

يغيّر باقة الاستضافة لمشروع موجود.

<div dir=ltr>

```bash
alusus-net change-plan <projectName> <planName> [promotionCode] [apiToken]
```

</div>

**المعطيات:**
- `projectName`: اسم المشروع على الأسس نت
- `planName`: اسم باقة الاستضافة المراد التبديل إليها (تستخرج الأداة معرّفها تلقائيًا)
- `promotionCode` (اختياري): رمز ترويجي لتطبيقه على الباقة الجديدة
- `apiToken` (اختياري): رمز API للأسس نت. إذا لم يُوفَّر، ستتم مطالبتك بتسجيل الدخول

**مثال:**

<div dir=ltr>

```bash
alusus-net change-plan my-app pro-plan
```

</div>

#### backup-db

يستنسخ قاعدة بيانات حاويتك ويُحمّل النسخة الاحتياطية.

<div dir=ltr>

```bash
alusus-net backup-db <projectName> <backupPath> [apiToken]
```

</div>

**المعطيات:**
- `projectName`: اسم المشروع على الأسس نت
- `backupPath`: المسار لحفظ ملف النسخة الاحتياطية لـ PostgreSQL إليه
- `apiToken` (اختياري): رمز API للأسس نت. إذا لم يُوفَّر، ستتم مطالبتك بتسجيل الدخول

**مثال:**

<div dir=ltr>

```bash
alusus-net backup-db my-app ./backup.sql
```

</div>

#### restore-db

يرفع ويسترجع قاعدة بيانات إلى حاويتك.

<div dir=ltr>

```bash
alusus-net restore-db <projectName> <backupPath> [apiToken]
```

</div>

**المعطيات:**
- `projectName`: اسم المشروع على الأسس نت
- `backupPath`: مسار ملف النسخة الاحتياطية لـ PostgreSQL المراد رفعه
- `apiToken` (اختياري): رمز API للأسس نت. إذا لم يُوفَّر، ستتم مطالبتك بتسجيل الدخول

**مثال:**

<div dir=ltr>

```bash
alusus-net restore-db my-app ./backup.sql
```

</div>

## التوثيق (Authentication)

تدعم الأسس نت عدة طرق للتوثيق:

1. **تسجيل الدخول التفاعلي**: أدخل اسم المستخدم وكلمة السر عند مطالبتك بذلك
2. **التحقق متعدد العوامل (MFA)**: مدعوم مع رموز ثقة (trust tokens) لعمليات تسجيل الدخول اللاحقة
3. **رموز API**: مرّر رمز API للاستخدام غير التفاعلي (مثل أنظمة CI/CD)

تُحفظ بيانات التوثيق في `~/.config/alususnet.conf` افتراضيًا. يمكنك تغيير هذا المسار باستخدام متغير البيئة `ALUSUS_NET_CONFIG_PATH`.

## متغيرات البيئة

- `ALUSUS_NET_HOST`: تجاوز مضيف الأسس نت الافتراضي (الافتراضي: `https://alusus.net`)
- `ALUSUS_NET_CONFIG_PATH`: تجاوز مسار ملف الإعدادات الافتراضي (الافتراضي: `~/.config/alususnet.conf`)

## متطلبات اسم المشروع

يجب أن يستوفي اسم المشروع الشروط التالية:
- أن يحتوي فقط على أحرف إنجليزية صغيرة (a-z) وأرقام (0-9) وشرطات (-)
- ألا يبدأ أو ينتهي بشرطة
- أن يطابق النمط: `^[a-z0-9\-]+$`
